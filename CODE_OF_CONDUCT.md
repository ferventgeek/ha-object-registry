# Code of Conduct

This is a small, friendly open-source project. We're inspired by the [GitHub Community Code of Conduct](https://docs.github.com/en/site-policy/github-terms/github-community-code-of-conduct) and ask that all participants do the same.

## The short version

Be kind, be constructive, assume good intent. This project exists to help the Home Assistant community — let's keep it that way.

## What great looks like

Home automation attracts curious, creative people, and that energy is what makes this community great. We'd love to see:

- Sharing how you're using the integration in your own home, however weird or wonderful
- Helping others debug their setup with patience and generosity
- Suggesting improvements with a clear explanation of the problem you're solving
- Celebrating what works, not just flagging what doesn't
- Welcoming newcomers who are just finding their feet with Home Assistant

The best GitHub projects feel like a conversation, not a ticket queue. That's what we're going for here.

## Unacceptable behavior

- Harassment, personal attacks, or discriminatory language of any kind
- Trolling, deliberate disruption, or bad-faith contributions
- Posting others' private information without consent
- Any conduct that would be unwelcome in a professional setting

## Enforcement

This project is maintained by one person. I reserve the right to remove comments, close issues, or block users who violate this code of conduct. I'll do my best to be fair, but my first priority is keeping this a welcoming space for the community.

If you experience or witness unacceptable behavior, please reach out privately via GitHub.
